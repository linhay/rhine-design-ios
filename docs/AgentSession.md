# UIKit Agent 会话组合候选

本页承接 [#109](https://github.com/linhay/rhine-design/issues/109)，将消费场景建议收敛为独立 iOS 组合规范与合成展台配方。它不是已发布能力，也不新增公开 Chat、Timeline、网络或授权 API。基线为 iOS / iPadOS 17.0、UIKit 与 Auto Layout；复用 [基础组件](Components.md) 和语义 tokens，不转换 Web DOM/CSS 或引入 SwiftUI。

## 范围与所有权

阅读正文是主要任务，输入、运行控制和一次性授权是相关操作。正文区必须可读到长内容末尾，操作区只承载动作；连接、运行和发送结果用内容区的准确文字说明，不能只靠颜色或进度图标表达。

| 内容 | 所有者与边界 |
| --- | --- |
| 连接、认证、协议与事件顺序 | 宿主。组合不建立连接、不推断真实主机状态；恢复连接后由宿主核对权威状态。 |
| 消息、流式片段与稳定标识 | 宿主。展示层按稳定标识更新内容；协议去重、历史分页与存储不属于本次实现。 |
| 草稿、发送请求与接受结果 | 宿主。样例仅保留页面内合成草稿；进程终止后的恢复、持久化与真实请求幂等由消费应用实现。 |
| 运行、停止与授权请求 | 宿主。按钮报告意图，服务端确认决定最终结果；展示和关闭弹窗都不能代替授权决定。 |
| 布局、阅读位置与页面焦点 | UIKit 组合。按有效容器、系统键盘与 Dynamic Type 布局，维护正在阅读的位置；不复制组件内部实现。 |

本次为有限合成消息、单行草稿和单个待处理授权的最小配方。多行输入、附件、富文本渲染器、无限历史列表、并发授权队列和自动重试不在本次实现范围。

## 正文与阅读位置

- 正文采用主要文字层级；推理片段与工具事件使用可辨认的名称和辅助文字层级。长说明自然换行并可滚动读完，不用固定行高或不可恢复的截断隐藏结果。样例中的推理片段也是合成展示内容。
- 内容变动前记录是否正在跟随底部。只有已经处于底部且没有主动阅读历史时，追加片段才继续跟随；不能在更新后重新判断距离并将用户拉回底部。
- 用户上滑阅读历史后，追加消息或当前消息增长都保持阅读锚点；“查看最新”是恢复底部跟随的显式入口。流式更新不移动输入焦点，也不逐片段强制 VoiceOver 朗读或聚焦。
- 键盘、字号和容器变化后重新布局，保持正在阅读的内容与相对位置。字号变化须在正文实际重排完成后恢复：原本跟随底部的继续处于底部，阅读历史的保留同一消息行及其相对视口位置；不能将重排中间状态产生的滚动当成新的阅读锚点。没有自定义滚动动画也必须保留同样的可达性。
- 未来加入顶部历史分页时，需以稳定消息标识与视口内偏移恢复锚点，补充加载前后证据。本次不实现分页，不能用追加测试声称分页锚点通过。

## 输入与发送确认

样例复用 `RhineTextField` 的持久标签和原生单行输入，以及 `RhineButton` 的动作门禁。输入区域随 `keyboardLayoutGuide` 布局；大字号下允许增高或纵向安排，不能让发送/状态文字被键盘永久遮挡。软件键盘关闭与发送是不同动作；输入法组合期间不擅自修剪或改写文本。

滚动区域保留原生输入的固有高度，不把大字号文本压缩进最小触控高度。验收须分别滚到完整输入框与发送按钮，核对实际字体行高、文本绘制、光标位置和键盘边界；发送可点击不能替代草稿可读。

软件键盘与大字号使可用高度不足时，编辑态暂时收起导航栏，将“查看最新”移入输入区域，与字段和发送共用可滚动容器。结束编辑或离开页面时恢复原导航栏状态；在紧凑编辑态点击“查看最新”，主动结束编辑、恢复可见正文，再定位最新内容。滚动输入区域不主动收起键盘；发送也不先强制收键盘，锁定草稿并禁用编辑后，系统可能结束编辑，须按实际行为记证。

导航恢复须从正常 Gallery 推入后检查，独立配方启动入口没有返回按钮。通过原生 Done 结束编辑后，以及旋转到充足高度时，同一页面的草稿保留且不自动发送；离开后宿主导航恢复。pop退出导航栈返回Gallery，再进入创建新的页面和模型，不承诺跨实例恢复草稿；临时遮挡或后台回来仍遵循同一实例的状态保留规则。

一次发送在同步回调内锁定本次草稿与请求身份，进入“等待接受”，避免重复点击或辅助激活重复提交。只有宿主提供匹配请求的接受事实，才能将它标为已发送并消费对应草稿；“已接受”也不表示 Agent 运行完成。

连接中断、超时或结果未知时显示“尚未确认”，保留文本，不显示成功，不自动重发。已明确失败和结果未知需可区分；可否重新编辑或显式重试由宿主依据请求状态决定，不能仅因重连就重新发送。迟到或重复回调要核对请求身份与当前状态，不能清空后续的新草稿、重复添加消息或使旧请求覆盖新状态。

## 连接、后台与运行

连接中、离线、已连接分别表达连接事实；运行中、停止请求已接收、任务已停止分别表达运行事实。连接中断或页面进入后台不把运行中改成已停止，停止请求已接收也不能提前显示已停止。

进入后台与回来时保留会话内容、未确认草稿和授权状态。回来先表达重新连接或等待同步，收到宿主确认后再刷新运行事实，不伪装实时联网或自动重发请求。页面资源、通知观察者与合成流任务应在相应生命周期释放；迟到事件不能对已经离开的页面弹出授权界面。

### 宿主运行环境退出与列表恢复

以下约定承接 [消费侧反馈](https://github.com/linhay/rhine-design/issues/109#issuecomment-6514965517)，补充宿主接入边界，不表示本合成会话展台已经实现运行环境管理或会话列表。观察到环境退出时旧内容仍显示“正在读取”，只能证明展示状态未收口，不能据此判定列表刷新导致环境退出。

- 宿主确认本机运行环境已停止或退出后，结束该环境的列表读取加载状态，保留已获取内容，在原状态区明确“环境已退出／当前为已有内容”。旧行不能继续表达在线或实时状态；不默认增加全屏遮罩或独立错误页。临时断线仍只表达连接事实，不能推断远端 Agent 运行已停止。
- 回调须同时归属正确的工作区、运行环境实例、连接代次和读取请求。切换工作区、环境退出或新连接开始后，旧请求的成功与失败都不能覆盖当前状态、清空新内容或重新显示加载中；取消请求本身不能代替回调有效性检查。
- 恢复入口进入宿主已有的运行环境管理页。环境重新就绪后使用本次实例的实际连接信息重新连接并核对权威状态，不复用旧连接信息，不自动重放消息、置顶或归档等写操作。
- 写操作结果未知时保留原工作区、目标和请求身份；恢复后先核对该目标的结果，再由宿主决定后续动作，不能将当前选择误作原操作目标。其他工作区的失败不污染当前列表。

宿主应验证三条具体路径：保留旧内容时读取失败或环境退出；切换工作区后旧读取失败晚到；新环境恢复后旧读取成功或失败晚到。分别观察加载状态结束、旧快照标识、恢复入口及迟到结果隔离。消费侧修复和真实 UI 回归仍待完成；这些路径是接入核对项，不计为本展台已有 PASS，也不新增到当前 #109 合成配方的关闭条件。若需要上游实现会话列表，应先单独明确范围与验收。

## 一次性授权

每个请求包含稳定标识、请求内容与必要上下文。样例一次处理一个请求；未来需要队列时由宿主补充顺序及失效策略，不能静默覆盖当前请求。

- 有效待处理请求提供“允许一次”和“拒绝”；允许一次只对应当前请求，不建立永久信任。两者都报告明确意图，提交期间禁止重复决策，最终确认由宿主提供。
- 请求状态保存在宿主状态中，不能仅寄存在弹窗对象里。被其他弹窗遮挡或暂时无法呈现时保持待处理；遮挡结束后重新核对请求仍然有效再展示，不能丢请求或重复展示。
- 关闭其他弹窗不等于授权，关闭授权界面也不自动解释为拒绝。页面退出、交互关闭和重新进入时，由宿主明确保留/恢复策略，不制造默认同意。
- 已撤回请求立即变为不可操作；已展示界面退出，待展示请求取消。撤回与允许/拒绝并发时，处理回调前再次核对标识和有效状态，过期回调不得继续生效。
- 授权出现时将焦点交给请求上下文或合理入口；完成或撤回后返回仍然存在的触发入口或会话位置。隐藏或退出的内容不能继续参与辅助技术导航。真实 VoiceOver 的阅读、激活与归焦必须单独验收。

## 合成展台与验收

展台持续标明“合成演示”，通过显式场景控制注入片段、发送结果、断线/重连、运行与授权变化。它不访问真实主机，不请求系统权限；模拟后台/重连按钮与实际应用生命周期检查分别记证。底部跟随和授权撤回必须由实际交互验证，静态截图不能代替行为证据。

下表是必要检查，列出预期不表示已经通过；执行结果和精确源码/制品绑定记录到 [Validation](Validation.md)。普通状态与 Reduce Motion 下须能完成同一路径，不为验收添加装饰动画。

真实系统字号往返检查须保持同一应用进程，核对实际字体与重排后的底部或消息行位置；启动参数或应用内字号预览单独记证，不能代替运行中的系统字号变化。

| 场景 | 必须观察的结果 |
| --- | --- |
| 短/长正文、推理与工具混排 | 层级可辨、长内容末尾可读，主要结果和下一步动作可达。 |
| 底部跟随与历史阅读 | 底部追加继续跟随；阅读历史时连续追加及消息增高不抢位置；真实系统字号往返后分别保持底部或原消息行锚点；显式查看最新后恢复跟随。 |
| 等待接受、未知、失败与接受 | 未确认时原草稿保留，无自动重发；匹配接受才消费草稿；重复激活和迟到事件无额外提交或误清空。 |
| 实际软件键盘与辅助字号 | 当前输入、完整状态和发送动作可达；关闭键盘不发送。空间不足时可滚动到完整输入与发送动作，输入区域滚动不主动收键盘；紧凑态查看最新结束编辑并恢复可见正文。覆盖浅/深外观、窄内容及最大辅助字号的相关组合。 |
| 停止与后台回来 | 连接、运行、停止请求、已停止分别可辨；实际后台/前台后保留内容与未确认草稿，等待同步不伪造成功。 |
| 允许一次与拒绝 | 同一有效请求至多一次决策；上下文完整，未确认不宣称生效。 |
| 遮挡、撤回与过期回调 | 遮挡结束后有效请求仍在；展示中撤回退出；遮挡期间撤回不再出现；旧回调不激活撤回或新请求。 |
| 页面退出与辅助焦点 | 合成任务及观察者无遗留；回调不对离开页面弹窗，退出内容不残留于辅助导航，恢复目标合理。 |

| 环境缺口 | 当前状态与限制 |
| --- | --- |
| 最低 iOS / iPadOS 17.0 | **SKIPPED**：尚无可用的最低系统运行证据；较新模拟器结果不能替代，也不因此抬高声明下限。 |
| 真机 VoiceOver 与触控 | **SKIPPED**：尚无本候选的真实阅读、激活、归焦及触控证据；AX 树或自动化点击不算完成。 |
| iPad 最窄多任务窗口 | **PASS（有界）**：iPad A16 / Simulator27.0真实窗口375×486pt，两次进一步缩小保持下界；系统最大字号长正文末尾、软件键盘完整字段/发送、授权全文与允许/拒绝3项通过。测试`d1e1d09`，具体环境、制品与保留失败见[Validation](Validation.md#ipad-实际最窄窗口补验--2026-10-30)，不外推其他窗口/键盘位置。 |

这些缺口及 #35/#36 的既有失败继续保留。本任务的合成样例、消费方网络验证和依赖候选的历史通过互不补算；只有本任务承诺的验收实际完成后，才能据此决定合并或关闭，不自动发布版本或升级消费应用。
